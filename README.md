## Description
This is a simple Java program that demonstrates **single inheritance** using a parent class (`Animal`) and a child class (`Dog`).

## Features
- Demonstrates inheritance in Java.
- Uses the extends keyword.
- Inherits methods from a parent class.
- Calls methods using a child class object.

## Concepts Used
- Classes and Objects
- Single Inheritance
- Methods
- extends Keyword

## Program Output
Animal is eating.
Dog is barking.

## How to Run
1. Save the program as InheritanceExample.java.
2. Open Command Prompt in the file's folder.
3. Compile the program:
   javac InheritanceExample.java
   
4. Run the program:
   java InheritanceExample
